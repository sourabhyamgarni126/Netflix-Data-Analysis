# 🎬 Netflix Data Analysis (Python + Pandas + Matplotlib)

This project analyzes Netflix Movies & TV Shows dataset using Python.  
It includes data cleaning, visualizations, and insights.

---
## 📁 Dataset  
Dataset used: **netflix_titles.csv**  
(Downloaded from Kaggle)

---
## 🛠 Tools & Technologies  
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Jupyter Notebook  

---
## ▶️ How to Run  
Install libraries:
pip install pandas matplotlib numpy
Run notebook:
jupyter notebook netflix_analysis.ipynb
---
## 📊 Project Insights  
- Netflix has more Movies than TV Shows  
- USA, India, and UK are the top content-producing countries  
- Content releases increased significantly between 2015–2020  
- Most movies have a duration between 80–120 minutes  

---
## 📈 Key Visualizations  
- Pie Chart: Movies vs TV Shows  
- Bar Graph: Top 10 Countries  
- Line Chart: Movies Released Per Year  
- Histogram: Movie Duration Distribution
